# Rodrigo Muro Barajas – Portfolio

This project is a responsive personal portfolio website built to showcase my web development skills, projects, and professional profile.
The website includes information about my background, technical skills, and featured projects with live demos and GitHub repositories.

**Live Demo:**
https://rodrigomurob1997-coder.github.io/web_project_potrfolio_es/

---

## Features

- Responsive design (mobile, tablet, desktop)
- Profile section with professional summary
- Skills section with technology icons
- Projects section with:
  - Live demo links
  - GitHub repository links
- Contact section with social links
- Clean and structured layout using BEM methodology

---

## Technologies and techniques used

- **HTML5** for semantic structure
- **CSS3** for styling and layout
- **Flexbox** and **CSS Grid** for layout design
- **Responsive design** using media queries (320px, 768px)
- **BEM methodology** for scalable class naming
- **Git & GitHub** for version control
- **GitHub Pages** for deployment

---

## Purpose

The goal of this project is to:

- Demonstrate my front-end development skills
- Apply responsive design best practices
- Practice clean code organization
- Build a professional online presence
